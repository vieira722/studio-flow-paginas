Política de Privacidade do Studio Flow

Atualizada em 16/11/2026.

Quem usa

O Studio Flow é um aplicativo de uso pessoal, executado localmente no computador do desenvolvedor. Só o desenvolvedor o utiliza, com as próprias contas do Google e canais do YouTube.

Dados acessados

Com a autorização do proprietário do canal, o aplicativo acessa, pela API do YouTube: envio e edição de vídeos, legendas, miniaturas e playlists dos canais autorizados, e métricas de desempenho desses canais (YouTube Analytics).

Como os dados são usados

Esses dados são usados exclusivamente para publicar e gerenciar os vídeos dos canais do próprio desenvolvedor e acompanhar o desempenho deles. Não são usados para publicidade, perfilamento ou qualquer outra finalidade.

Armazenamento e compartilhamento

As credenciais de acesso ficam guardadas apenas no computador do desenvolvedor. Nenhum dado do YouTube ou da conta Google é vendido, transferido ou compartilhado com terceiros.

Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados de Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
